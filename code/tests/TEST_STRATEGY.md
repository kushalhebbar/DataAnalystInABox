# Test Strategy

## Overview
Multiple test scenarios ensure the pipeline is resilient across different data quality conditions and problem types.

---

## Test Runner

### Location
`code/tests/test_runner.py`

### Usage

```bash
# Run all tests (single iteration each)
poetry run python code/tests/test_runner.py

# Run with auto-answer loop (auto-generates answers, loops until no questions)
poetry run python code/tests/test_runner.py --auto-answer

# Run specific config with custom max iterations
poetry run python code/tests/test_runner.py --config code/tests/test_config.json --auto-answer --max-iterations 3
```

### Modes

| Mode | Command | Behavior |
|------|---------|----------|
| **Single iteration** | `poetry run python code/tests/test_runner.py` | Runs each test config once, reports questions generated |
| **Auto-answer** | `--auto-answer` | Uses LLM to auto-generate answers, loops until no questions remain |
| **Single config** | `--config <path>` | Run one specific config instead of all three |
| **Max iterations** | `--max-iterations N` | Limit auto-answer loop (default: 5) |

### What It Does

1. Loads test config JSON
2. Creates `Inputs` and `RunState`
3. Invokes the LangGraph pipeline
4. (If `--auto-answer`) Auto-generates answers using LLM, re-runs until no questions
5. Saves artifacts to `artifacts/<run_id>/state.json`
6. Reports pass/fail based on errors

## Expected Outcomes

### Baseline Test
- Quick execution (< 10 seconds per iteration)
- No data quality warnings
- Clean PII check
- `late_delivery` identified as target

### Stress Test
- Flags ~60 missing values
- Detects 5 duplicate rows
- Warns about impossible values
- Identifies PII columns
- `late_delivery` scored highest as target
- Shows sample rows with issues

### Exploratory Test
- Multiple target candidates suggested
- `late_delivery` scored highest
- Questions about target selection generated

Each test run saves:

```
├── state.json           # Full RunState dump
└── explainability.log   # Human-readable lineage (generated by Streamlit)
```

## Adding New Test Scenarios

1. **Create dataset** (optional):
   ```bash
   # code/tests/data/your_dataset.py
   ```

2. **Create config**:
   ```json
   {
     "csv_path": "code/tests/data/your_dataset.csv",
     "problem_statement": "...",
     "audience": "...",
     "goal_type": "analysis|prediction|unsure",
     "success_metric": "...",
     "data_dictionary": "...",
     "target_column": "column_name or null"
   }
   ```

3. **Run**:
   ```bash
   poetry run python code/tests/test_runner.py --config code/tests/your_config.json --auto-answer
   ```

## Streamlit Test Mode (Manual UI Testing)

For interactive UI testing with pre-populated fields:

```bash
TEST_CONFIG=code/tests/test_config.json poetry run streamlit run code/app/streamlit_app.py
```

This auto-fills the Streamlit form but still requires clicking "Run Phase 1" manually.
